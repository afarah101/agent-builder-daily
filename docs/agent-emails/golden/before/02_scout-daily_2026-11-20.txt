CASE STUDY OF THE DAY
Cap-and-Track: Optimizing LLM Inference Request Dispatch Across Shifting Capacity
Cap-and-Track lets you adapt LLM inference dispatch to changing GPU capacity and request size without hard‑coding a rate. They built an async dispatcher that rejects requests early when resources are full, then uses those refusals to probe capacity and refill queues, cutting GPU use by 43% in production.

RESEARCH RADAR
- GateWatch: Low-Overhead LLM Monitoring with Boolean Circuits (50/75)
  GateWatch offers a very lightweight way to watch what large language models (LLMs) do by turning a few key features into simple Boolean rules. They built a system that keeps memory use down by 99.98% and adds almost no lag when running many probes on a model like Gemma‑2‑9B. The result is accurate monitoring that almost matches heavier methods while staying fast and tiny.
  https://arxiv.org/abs/2611.24619v1
- PIPETTE: Prompt Injection Purple-Teaming for Robust LLM Agents (35/75)
  PIPETTE tackles prompt injection attacks on LLM agents by creating a purple‑team framework that pushes red‑team attacks to cover many strategies, then trains defenders with those attacks to build robust agents. It built a dictionary‑reward system for wider attack discovery and an on‑policy training pipeline that keeps normal tasks working while blocking injection. The result was agents with almost zero success for static attacks and strong resistance to adaptive attacks without losing performance.
  https://arxiv.org/abs/2611.24362v1
- Mechanistic Critics for Sample-Efficient NPU Design-Space Exploration (25/75)
  CriticNPU is a tool that speeds up designing neural processing units (NPUs) for large‑language‑model inference by using a fast, physics‑based model to guess whether a new hardware setup will be faster before running a slow simulator. It filters out poor candidates early and then refines the design using real simulation data, cutting the number of expensive simulations in half while matching or beating the best latency in most test cases. This directly helps IT engineers who design or optimise custom AI chips or select cloud AI services, giving a faster way to pick the right hardware configuration for specific workloads.
  https://arxiv.org/abs/2611.24733v1
