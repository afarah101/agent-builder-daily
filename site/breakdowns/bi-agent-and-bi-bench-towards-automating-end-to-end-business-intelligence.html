Detailed summary

The study introduces BI‑Agent, an end‑to‑end business intelligence automation framework that leverages large language models (LLMs) in combination with specialized data tools. BI‑Agent is designed to handle the entire BI pipeline: it automatically identifies relevant tables in a data lake, applies schema‑aware transformations, performs joins across heterogeneous sources, and generates natural‑language answers to business questions. The authors also created BI‑Bench, a benchmark dataset derived from real‑world dashboards, to evaluate the performance of BI agents. Experiments show that a tool‑augmented LLM can improve answer accuracy by up to 40 % compared to a vanilla LLM baseline. The improvement stems from the agent’s ability to query external tools (e.g., SQL engines, data‑cleaning libraries) and to reason about schema relationships. For enterprise IT, this research demonstrates a viable path to reduce the manual effort required for data preparation, ETL orchestration, and report generation. By automating these steps, organizations can accelerate insight delivery, lower the skill barrier for analysts, and reduce the risk of human error in data handling. The benchmark also provides a reproducible evaluation framework that can be used to compare different LLM‑based BI solutions. In real‑world deployments, the approach could be integrated into cloud data platforms (AWS Redshift, Azure Synapse, Snowflake) to enable self‑service analytics, while the tool‑augmented agent can be exposed via APIs for downstream applications. The study underscores the importance of coupling LLMs with domain‑specific tooling and offers a concrete methodology for measuring gains in accuracy and productivity.
