Detailed summary

The study investigates GPU memory contention during large language model (LLM) inference, a critical bottleneck for enterprises deploying generative AI workloads. The authors propose a scheduling rule that prioritises inference requests by a composite metric, cμ, which integrates compute speed (c), memory bandwidth (μ), and memory usage. Using a fluid‑model framework, they prove that the cμ rule asymptotically minimises average latency while maximising throughput under a hard memory constraint. Experimental validation on an NVIDIA H800 GPU demonstrates that the rule reduces average inference latency by up to 18 % compared to round‑robin or FIFO scheduling, without sacrificing overall throughput. For enterprise IT, this means that existing GPU clusters can deliver faster response times for AI services without additional hardware investment. The rule is algorithmically simple, requiring only per‑request profiling of compute and memory characteristics, and can be integrated into existing job schedulers or container orchestrators. Real‑world implications include improved user experience for AI‑powered applications, higher utilisation of GPU resources, and a clearer pathway to scaling LLM inference in production environments. The study also provides a theoretical foundation for future extensions to multi‑GPU or distributed settings, making it a valuable reference for architects designing AI‑centric infrastructure.
