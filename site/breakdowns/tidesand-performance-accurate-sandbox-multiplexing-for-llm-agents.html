TideSand: Performance-Accurate Sandbox Multiplexing for LLM Agents

Shulu Li, Hanchen Li, Xiaokun Chen, Qiuyang Mang · Academic Institution · 2026-11-23 · Generated 27 Nov 2026, 11:27

Summary

TideSand is a sandbox architecture designed to manage the execution of multiple large‑language‑model (LLM) agents on shared infrastructure. The study evaluated how dynamic resource allocation—specifically CPU and memory—could be leveraged to increase throughput while maintaining call accuracy. Researchers instrumented a cluster running several LLM agents that perform tool calls (e.g., API lookups, database queries). Instead of the conventional static reservation or overcommit strategies, TideSand introduced a scheduler that (1) shares CPU cycles across agents based on real‑time load, (2) swaps out idle memory pages to disk or a fast key‑value store, and (3) performs selective rollbacks only when a tool call fails or a policy violation is detected. The evaluation used a benchmark set of 10,000 tool‑call sequences across three LLM models. Results showed a 10× increase in overall throughput compared to a baseline reservation model and a 44% improvement in call accuracy versus an overcommit baseline. The accuracy gain was attributed to the rollback mechanism, which prevented stale or corrupted state from propagating to subsequent calls. For enterprise IT, these findings are significant because LLM agents are increasingly deployed in production environments where resource constraints and compliance requirements coexist. By intelligently multiplexing resources, organizations can reduce the number of dedicated GPU/CPU nodes needed, lower operational costs, and improve service reliability. Real‑world implications include the ability to run more concurrent AI workflows on existing hardware, faster time‑to‑value for AI initiatives, and a more robust audit trail for compliance. The study also highlights the importance of fine‑grained resource monitoring and rollback policies, suggesting that enterprises should invest in tooling that supports dynamic memory paging and state checkpointing. Ultimately, TideSand demonstrates that performance‑accurate sandboxing is not just a theoretical optimization but a practical lever for scaling LLM workloads in regulated, cost‑conscious environments.
