Detailed summary

FOSCAR is a research effort that addresses the bottleneck of decoding large‑language models (LLMs) when operating with extremely low‑precision key‑value (KV) caches. The study focuses on 2‑bit and 4‑bit quantized KV caches, which are attractive for reducing memory footprint and bandwidth but suffer from expensive scale‑and‑offset operations during attention computation. The authors introduce an affine folding technique that eliminates these per‑token scaling steps by folding the affine transformation into the attention kernel itself. They also develop a packing strategy that aligns the quantized values with the native Tensor Core data layouts on NVIDIA Hopper (H100) and Blackwell (B200) GPUs. The resulting GPU pipelines achieve 2–3× throughput gains over conventional FP8 and BF16 decoding pipelines, translating into a 341% increase in long‑context serving capacity for enterprise workloads that require extended context windows (e.g., legal document analysis, code generation, or scientific literature summarization).
