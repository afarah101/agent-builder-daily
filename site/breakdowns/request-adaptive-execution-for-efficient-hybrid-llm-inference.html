Request-Adaptive Execution for Efficient Hybrid LLM Inference

Fahao Chen, Xuzhe Yan, Qi Zhang, Peng Li · Academic Institution · 2026-10-27 · Generated 29 Oct 2026, 12:41

Summary

The study investigates a hybrid inference framework named Morph that dynamically selects a mix of Attention and State Space Model (SSM) layers for each incoming request to a large language model (LLM). Traditional LLM deployments use a static architecture, which forces all requests to traverse the same sequence of layers regardless of content or length. Morph instead re‑architects the model into modular blocks and, at runtime, chooses a fixed, request‑specific layout that minimizes unnecessary computation. The system also groups similar requests into batches and re‑uses contextual embeddings across calls to reduce redundant processing. Experimental results on several benchmark datasets show that Morph can cut inference latency by up to 3.87× and increase overall throughput by a comparable factor when compared to a baseline static model. The gains are most pronounced for short‑to‑medium length prompts, where the overhead of full attention layers dominates. For enterprise IT, this approach directly addresses the cost and performance constraints of running LLMs in production. By reducing compute cycles per token, organizations can lower GPU utilization, defer scaling events, and improve response times for latency‑sensitive applications such as chatbots, code assistants, or real‑time translation services. Moreover, the ability to batch similar requests and reuse context aligns with existing data‑center optimization practices, enabling smoother integration with autoscaling policies and spot‑instance usage. Real‑world implications include the potential to run larger models on existing hardware, the ability to meet stricter SLAs without additional infrastructure, and a reduction in carbon footprint due to fewer GPU hours. The study also highlights the importance of a modular model design and a flexible runtime that can adapt to varying workloads, suggesting a shift from monolithic LLM deployments to request‑adaptive pipelines in enterprise environments.
