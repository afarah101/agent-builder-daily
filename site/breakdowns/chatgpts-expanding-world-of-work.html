Summary

OpenAI has released a new dataset, OpenAI Signals, that tracks how ChatGPT is used across 165 distinct work activities in almost 100 countries. The data is mapped to the Intermediate Work Activities (IWAs) framework, a standard used by the U.S. Bureau of Labor Statistics to categorize tasks by skill level and domain. The dataset is published quarterly, covering Q1 2025 through Q3 2026, and is available to researchers and industry analysts. For enterprise IT teams, this represents a granular view of AI adoption that can be compared against internal task taxonomies, enabling a precise assessment of where ChatGPT is already embedded and where gaps exist. By aligning internal usage with the IWA categories, teams can benchmark against industry peers, identify under‑utilized AI capabilities, and prioritize automation initiatives. Vendors such as Microsoft Azure OpenAI Service, AWS Bedrock, and Google Cloud AI Platform already provide the underlying infrastructure for ChatGPT deployments, and the dataset can be integrated into existing BI tools (Power BI, Tableau, Looker) for real‑time analytics. The broader industry implication is a shift toward data‑driven AI strategy: organizations can move from ad‑hoc experimentation to evidence‑based investment, reducing risk and accelerating ROI. The dataset also supports compliance and governance by providing a clear audit trail of AI usage across roles, which is valuable for regulators and internal audit functions. In short, OpenAI Signals gives IT leaders a concrete, comparable metric set to justify AI spend, optimize workforce productivity, and stay ahead of competitive peers.

How to apply

Evaluate

- Inventory all ChatGPT or LLM usage across the organization: code generation, documentation, support tickets, data analysis, etc. - Map each use case to an IWA category using the OpenAI Signals taxonomy. - Capture volume metrics: number of prompts, tokens processed, time saved, and error rates. - Assess current infrastructure: compute resources, network latency, and integration points with existing systems (GitHub, Confluence, ServiceNow).

Propose

- Build a business case that ties ChatGPT usage to measurable outcomes: reduction in ticket resolution time, increased code coverage, or faster onboarding. - Use the OpenAI Signals dataset to benchmark your organization against peers in the same industry and geography. - Include cost metrics: compute cost per prompt, storage, and potential savings from reduced manual effort. - Present a phased ROI model: immediate savings from automation, mid‑term productivity gains, and long‑term strategic benefits such as faster feature delivery.

Tools to consider

- Microsoft Azure OpenAI Service (for seamless integration with Azure DevOps and Power BI). - AWS Bedrock (for multi‑model access and native IAM controls). - Google Cloud Vertex AI (for model deployment and monitoring). - OpenAI API (direct access for custom tooling). - BI platforms: Power BI, Tableau, Looker for visualizing OpenAI Signals data. - Governance tools: Collibra, Alation, or Microsoft Purview for data lineage and compliance.

Risks to flag

- Technical: model drift, prompt leakage, and insufficient fine‑tuning leading to inaccurate outputs. - Compliance: GDPR (UK) data residency, data minimization, and lawful basis for processing. - Operational: over‑reliance on LLMs for critical decisions, lack of audit trails, and insufficient monitoring of model usage. - Vendor lock‑in and cost volatility from API usage.

Quick win

- Deploy a lightweight ChatGPT bot in the internal knowledge base (e.g., Confluence) to auto‑generate documentation from code comments. - Configure a simple usage dashboard that pulls OpenAI Signals data via API and displays prompt counts and token usage per team. - Complete within 30 days with minimal infrastructure changes.

Long-term play

- Over 6–12 months, develop a centralized AI operations center that manages model lifecycle, monitoring, and governance. - Integrate OpenAI Signals with the organization’s data catalog to maintain a single source of truth for AI activity. - Expand to multi‑model orchestration, allowing teams to switch between OpenAI, Anthropic, and proprietary models based on cost and performance. - Implement a continuous improvement loop: collect feedback, retrain models, and update IWA mappings to reflect evolving business processes.
