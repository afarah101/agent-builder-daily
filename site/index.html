Secure Speculative Decoding for Large Language Models

Yichi Zhang, Zhiqi Wang, Neil Gong, Yuchen Yang · Academic Institution · 06 Oct 2026

The paper studies whether speculative decoding – a speed‑up technique for large language models that uses a smaller draft model to propose tokens before confirming them with a larger target model – can leak information or be tampered with. The authors built an experimental framework that injects attacks into the draft model and measures how often the target model accepts leaked tokens. Results show that certain attack patterns can reveal sensitive content, highlighting a new security risk for LLM deployments.

Selective Critique for Cost-Aware LLM Agents in Long-Horizon Decision Making

Heewon Park, Somin Im, Minhae Kwon · Academic Institution · 05 Oct 2026

SAG introduces a cost‑aware gating system that only triggers an external critique when a large‑language‑model agent is likely to make a costly mistake, reducing token usage and latency in long‑horizon tasks. The authors built a prototype that selectively calls a critique module during autonomous decision making, showing that it cuts token consumption by about 40% while keeping error rates low. This approach is directly relevant to cloud‑hosted LLM services and could optimise cost and performance for long‑running agents.

HOW TO APPLY THIS

If you manage LLM agents in the cloud, here is what to do: 1) implement a gating check that evaluates the confidence or risk of each decision step; 2) only invoke the critique or external review when the gate flags high risk; 3) monitor token usage and latency to confirm the 40% savings reported.
