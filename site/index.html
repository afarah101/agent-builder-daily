An Interpretable Memory Decision Controller for LLM Agents Based on Three-Signal Complementarity: Decoupling Confidence and Consistency

Yiming Zhang, Jinghong Zhang, Haoran Zhao, Yiren Ma · Academic Institution · 18 Sep 2026

The paper introduces a new memory decision controller for large language models that separates a model’s confidence in a retrieved memory from its consistency with other memories, reducing hallucinations when memories conflict. By adding a three‑signal complementarity check, they built a system that only injects memories when both confidence and consistency are high, cutting hallucination rates in RAG setups. The result is a more trustworthy AI that still benefits from memory recall.

HOW TO APPLY THIS

If you manage cloud‑based LLM deployments, check whether your RAG pipeline uses a memory decision controller: step 1, add a confidence‑score filter; step 2, add a consistency‑check against other retrieved memories; step 3, only inject memories that pass both filters. This will reduce hallucinations and improve reliability of AI services.

RAFT: A Stateful Retrieval-Augmented Framework for Troubleshooting Agents

Mingxuan Zhang, Xiaowen Wang, Anupma Sharan, Zhengyi Chen · Academic Institution · 17 Sep 2026

RAFT turns past support cases into step‑by‑step state chains and then pulls in the exact intermediate states that match an ongoing issue, giving agents precise guidance rather than generic document snippets. The system was built on a new RAG framework that treats each case as a directed timeline, and it showed a 30% faster resolution time in pilot tests. For cloud infra managers, this means better, faster troubleshooting of recurring incidents.

HOW TO APPLY THIS

If you manage cloud infrastructure, here is what to do: 1. Map your existing support tickets into a stateful timeline (e.g., incident start, diagnostic steps, resolution). 2. Feed these timelines into a RAFT‑compatible RAG tool to enable state‑aware retrieval. 3. Use the retrieved intermediate states to guide engineers through similar past incidents, reducing troubleshooting time.
