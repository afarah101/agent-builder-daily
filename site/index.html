PrivDrift: Auditing User-Secret Leakage Under Topic Drift in Active LLM Conversations

Luciano Maldonado · Academic Institution · 24 Sep 2026

PrivDrift is a tool that checks if sensitive data users share in a chat with a large language model can still be extracted after the conversation moves to unrelated topics. It provides 1,000 test dialogues with hidden secrets and measures whether those secrets can be recovered by later prompts. The result is a benchmark that shows how well different LLMs hide or expose user data over topic shifts.

HOW TO APPLY THIS

If you manage cloud-hosted LLM services, use PrivDrift to audit your models: 1) run the 1,000 dialogue tests on your deployed model, 2) record any secrets that are recovered after topic drift, 3) adjust your prompt filtering or privacy safeguards to eliminate recoverable secrets.
