Navnit Shukla, Kamal Pandey, Omsankar Tiwari · Academic Institution · 18 Jul 2026

This research solves the problem of data leakage in multi-tenant deployments of Retrieval-Augmented Generation systems by introducing TurboVec, a cost-efficient private retrieval system. The researchers built TurboVec using TurboQuant, a codebook-oblivious scalar quantizer. The result is a system that maintains tenant isolation without degrading recall on selective queries.
