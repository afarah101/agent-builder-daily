Asymptotic Optimality of $cμ$-Rule for LLM Inference Scheduling under Memory Constraint

Zhenghao Li, Shengbo Wang, Nian Si·03 Nov 2026

This study tackles the problem of GPU memory contention during large language model inference by creating a scheduling rule that prioritises requests based on their combined compute speed, memory bandwidth and memory usage. The authors built a fluid‑model‑based cμ priority rule and proved it is optimal for minimizing latency and maximizing throughput, then validated it on an NVIDIA H800 GPU. As a result, the rule can cut average inference latency while keeping throughput high.

How to apply: If you manage LLM inference on GPUs, use the cμ rule: 1) measure each request’s expected compute speed, memory bandwidth and KV‑cache size; 2) compute μ for each class; 3) schedule requests by descending c×μ value to minimise latency and maximise throughput.
