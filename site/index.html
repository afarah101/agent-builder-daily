Prune First, Decide Fast: Scalable Semantic Query Processing with JEVDB

Zhengle Wang, Hanxu Yan, Fuheng Zhao, Chunwei Liu · Academic Institution · 01 Oct 2026

Semantic databases that use large language models for every decision are slow and expensive. JEVDB replaces most decisions with lightweight, typed models and only asks a generative LLM when it really needs to, while also pruning data with semijoin reduction and Semantic Bloom Filters, leading to faster and cheaper queries.

HOW TO APPLY THIS

Not directly applicable to routine cloud infrastructure management unless you are running semantic‑query workloads on a database; if you do, evaluate JEVDB for cheaper, lower‑latency processing.

View Technical Reasoning
IMPACT0/25
MATURITY0/25
MONETISATION0/25

The paper proposes a new approach to semantic query processing that replaces heavy generative LLM usage with fast typed decision models and selective LLM escalation, reducing latency and cost for data querying workloads. This is a surprising and practical improvement for IT engineers dealing with data integration, ETL, and BI pipelines on cloud platforms. It directly impacts how engineers build and optimize semantic layer solutions over structured and unstructured data in Azure Synapse, AWS Redshift, or Snowflake, and provides a concrete strategy to lower inference costs. The methods (Yannakakis-style semijoin reduction + Semantic Bloom Filters) can be adopted within 90 days to prototype or augment existing data pipelines, offering a tangible value proposition. The novelty score reflects the practical system contribution rather than purely academic insight.
