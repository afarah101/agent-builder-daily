From Backlog Items to Security Guidance: Towards Continuous Security Compliance

Ignacio García Núñez, Florian Angermeir, Fabiola Moyón Constante · Academic Institution · 29 Jul 2026

This research solves the problem of making security requirements explicit in software development by building an NLP-based system that detects security-relevant backlog items and links them to relevant security requirements. The system combines a security-relevance classifier with a retrieval-augmentation module to provide timely guidance on applicable requirements. The result is improved continuous security compliance in regulated domains.

HOW TO APPLY THIS

If you manage cloud-based software development, here is what to do: review your current backlog management process to identify potential security gaps, consider implementing an NLP-based enrichment system to detect security-relevant items, and ensure your team has access to timely security guidance and requirements. This flags a risk: if your organisation uses agile development methodologies, check your backlog items for security relevance immediately. Not directly applicable to general IT infrastructure work outside of software development.
