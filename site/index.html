Jean Lucien Randrianantenaina, Hung Nguyen, Nasib Ullah, Jinbin Zhang·30 Oct 2026

ETAPS gradually prunes and adapts sparse models, keeping each step small so the model can recover quality without large optimizer states. It outperforms the previous state‑of‑the‑art at 50‑90% sparsity and reduces GPU‑time and memory by up to 49% and 5× respectively. This could help you run cheaper, high‑sparsity LLMs in production.

How to apply: If you manage large language models, here is what to do: 1) Use ETAPS to prune in stages, 2) Keep the sparse delta small and train it continuously, 3) Monitor perplexity to ensure quality stays above baseline.

Context as Infrastructure: Knowledge Compilation for Retrieval in Agentic Systems with Harnesses

Zhichang Yu, Baining Cao, Sbaaoui Idriss, Qi Wang·30 Oct 2026

This research shows how to pre‑process and organise knowledge into structured formats (like claim‑evidence trees, entity graphs, timelines) so that an AI agent’s search loop uses only the minimal necessary context, cutting query tokens by 91% and reducing latency from 140s to 30s. The authors built an open‑source pipeline called RAGFlow that turns a chaotic retrieval loop into five disciplined stations, giving the agent a curated, governed context instead of a raw ranked list of passages. For cloud infrastructure managers, this means a way to host and serve structured knowledge bases that improve agent efficiency and governance without adding new retrieval engines.

How to apply: If you manage cloud infrastructure, set up RAGFlow on your Kubernetes cluster: 1) ingest your documents into the compilation pipeline to generate claim‑evidence trees; 2) expose the compiled store via a REST API; 3) route your agents’ queries through the RAGFlow harness to cut token use and latency.

Sizhe Chen, Yibo Peng, Jaewon Chang, Chawin Sitawarin·30 Oct 2026

SecPO introduces a new loss function and adversarial training pipeline that dramatically reduces prompt‑injection attack success rates on LLMs, while keeping normal performance intact. The researchers trained a Qwen‑3.6‑27B model with SecPO and strong synthetic attacks, cutting ASRs 1.5‑14.5× compared to previous methods and 2.4‑4.6× versus standard DPO loss. This shows a practical way to harden AI agents against injection attacks without hurting their usefulness.

How to apply: If you manage cloud‑hosted AI services, run the SecPO training code on your models: 1) generate strong injected inputs with their AT pipeline, 2) fine‑tune your model using the SecPO loss, 3) test against known adaptive attacks. This will lower injection success rates and keep service quality high.

ACCT: Asymmetric Cross-LLM Context Transfer

Yuzhe Liu, Haolin Tian, Tonghan Wang·30 Oct 2026

ACCT lets you move the key‑value cache (the context) from a smaller LLM to a larger one without re‑running the original prompt, saving up to 20× faster inference and cutting memory use by 75%. They built three light components that pick useful tokens, decide how many to keep, and convert the cache into a format the target model can use. The result is that the larger model can infer faster and with fewer tokens, matching or beating its usual performance.

How to apply: If you manage multi‑model LLM deployments, step 1: identify which models in your stack can be paired for cross‑cache transfer; step 2: apply a KV selector to keep only the most relevant context tokens within your budget; step 3: convert and load the sparse KV into the target model before inference. This can cut inference time and memory in your cloud infra.

Flide: Accelerating Decision Inference with Exact State Forking

Bobo Li, Jiajia Song, Hao Fei, Wynne Hsu·30 Oct 2026

Flide is an inference engine that speeds up decision‑making models by avoiding redundant calculation and keeping results mathematically exact. It does this by flattening token streams and using GPU‑based indices to fork attention across different decision branches, allowing up to 9.5× faster queries than existing engines while maintaining precision. This means faster, more accurate LLM‑driven decision systems for applications that need low latency and high reliability.

How to apply: If you manage LLM‑based decision systems, step 1: replace your current inference engine with Flide; step 2: update your deployment to use the flattened token stream format; step 3: test performance and precision against your baseline, aiming for up to 9.5× speed improvement without sacrificing accuracy.
