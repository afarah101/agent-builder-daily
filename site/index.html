Make the Adversary Spend More: Stateful Deception as a Cost-Exchange Primitive for AI-Era Cyber Defense

Alessandro Cantelli-Forti, Isabella Marasco, Hosam Alamleh, Giada Boschi·25 Nov 2026

This research shows that using a persistent state‑based deception system, powered by a local language model, can force attackers to spend more time and resources while keeping defender cost lower. They built an SSH honeypot that keeps each attacker’s view consistent with their past actions and measured a 63 % reduction in defender effort compared to a basic LLM decoy. It is directly relevant to IT infrastructure managers looking to improve cost‑effective deception.

How to apply: If you manage SSH or similar services, integrate a persistent state honeypot: 1) set up Cowrie with a local LLM; 2) configure the LLM to only render state, not store it; 3) monitor and adjust Deception Exchange Rate to keep defender costs under 63 % of a basic decoy.

PersonaFactory: Stylistic User Prompt Augmentation with Synthetic Persona Bank

Bich Ngoc Doan, Hanna Yukhymenko, Imanol Schlag·25 Nov 2026

PersonaFactory builds a pipeline that creates a huge synthetic persona bank and augments training dialogues with user personas to improve style and intent preservation in LLMs. The system produces 740,000 detailed personas and 1.24 million persona‑styled conversations across 85 languages, and shows that these enriched data help models match user style without losing intent. It is not directly relevant to managing cloud infrastructure.
