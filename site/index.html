Oskar J. Hollinsworth, Alex F. Spies, Tigist Diriba, Adam Gleave · Academic Institution · 08 Oct 2026

Long Text to Predictive Features: LLM-Guided Blockwise Feature Engineering via Executable Program Search

Ziming Dai, Dabiao Ma, Ziheng Guo, Jack Dong · Academic Institution · 08 Oct 2026

The paper tackles the problem of extracting useful information from long, unstructured text for risk‑control models, a task that is usually slow and labour‑intensive. It introduces LLM‑BlockFE, an offline framework that turns text into small, executable feature‑generation programs so that the heavy LLM is only used once per document, not during live inference. The result is a faster, cheaper way to enrich structured models with text insights.

HOW TO APPLY THIS

If you manage cloud infrastructure, here is what to do: 1) collect your unstructured logs or documents; 2) run LLM‑BlockFE as a batch job on your data lake to generate reusable feature programs; 3) deploy those lightweight programs in your inference pipeline to avoid on‑line LLM calls.

The Last Human Gate: Forward Deployed Engineering for Governance Automation

Jeremy Canale · Academic Institution · 24 Sep 2026

The paper tackles the problem of too many human reviews in enterprise governance, proposing a framework that treats each governance gate as an automated contract. It builds a task‑substitution model that calculates when automation reduces overall human effort, showing that in many cases it actually increases labor. The result is a residual‑work threshold that helps decide when to automate gates.

HOW TO APPLY THIS

If you manage cloud governance, use the residual‑work threshold: 1) inventory all governance gates, 2) assess available data and authority checks, 3) apply the model to see if automation cuts or adds work. This flags a risk: if your org relies heavily on manual gatekeeping, check whether automation will raise total effort before rolling it out.
