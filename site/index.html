cua-speedrun: Standardized Benchmarking of the Speed of Computer-Use Agents

Pranjal Aggarwal, Lawrence Keunho Jang, Sean Welleck, Daniel Fried · Academic Institution · 30 Sep 2026

This research tackles the lack of reliable speed measurements for computer-use agents that work via GUIs, by creating a new benchmark called cua‑speedrun that standardises how speed is evaluated. They built a reproducible, containerised testing framework that runs CUA tasks on consistent hardware, showing that current agents can finish complex tasks faster than before but still need optimisation. The result is a tool that can help developers gauge and improve CUA performance, which can inform infrastructure scaling decisions.

HOW TO APPLY THIS

If you manage cloud infrastructure for CUAs, use cua‑speedrun to benchmark your agents: step 1, install the provided containerised benchmark suite; step 2, run it on a representative set of tasks; step 3, analyse the speed results to identify bottlenecks and optimise deployment resources.

ReSAIL: Mitigating Collapse in Iterative Agent Self-Distillation

Shengjie Jin, Hengbo Xu, Zelong Sun, YuJie Guo · Academic Institution · 30 Sep 2026

The research tackles the problem of performance collapse in iterative self‑distillation of large language model agents. The authors created ReSAIL, a plug‑in that prioritises informative interaction steps and preserves privileged‑information behaviour to keep agents improving. The result is a method that keeps deployment performance stable across cycles.
