LLM-Assisted Software Migration: from Module-Level Transformation to Repository-Level Integration

Yanan Zhang, Shengqi Liu, Tao Zhang, Yidi Liu·23 Nov 2026

The study reviews how large language models (LLMs) can be used to move whole software projects from one language or framework to another, showing that while module‑level changes work well, full repository migration still struggles with build reliability, behaviour testing, and non‑functional properties. They built a taxonomy of migration approaches, analysed 96 papers, and identified gaps in requirements support, agent coordination, and cost‑benefit assessment. This research is relevant: it highlights practical risks and offers a framework for planning LLM‑driven migrations.

How to apply: If you manage cloud infrastructure, use the taxonomy to map your migration stages: 1) catalogue modules needing change, 2) choose an agent type (agentless, single or multi‑agent) that matches your build pipeline, 3) integrate environment feedback loops to catch runtime behaviour gaps before full deployment.
