CARI: Cross-Boundary Adversarial Runtime Injection in Coding-Agent Workflows

Jie Fu, Shuang Wu, Ashish Kundu, Wendy Hui Wang·28 Oct 2026

CARI shows that a compromised development component can inject malicious instructions into the runtime feedback of coding agents, leading to resource exhaustion, data leaks, or state changes. The researchers built ten attacks across multiple languages and models, achieving up to 94.8% success, and proved the technique works on real product agents like Codex and Claude Code. This is relevant to cloud infra managers because insecure CI/CD or deployment services could become the injection vector.

How to apply: If you manage CI/CD or deployment services that provide runtime feedback to development agents, check that the feedback cannot be tampered with by other services; isolate feedback channels and validate authenticity before agents act on them.

Understanding and Mitigating Role Spoofing in LLMs

Ezra Edelman, Benjamin Edelman, Surbhi Goel, Eran Malach·29 Oct 2026

This study shows that large language models can be tricked into attributing text to the wrong role (role spoofing) by mixing fake structure and content cues, making them vulnerable to hijacking attacks. The researchers built a detection method using linear probes that reliably flags spoofed roles across different model settings. For IT infrastructure managers, the work highlights a new security risk with LLM‑powered tools but does not directly change day‑to‑day cloud ops.

How to apply: If you manage LLM‑enabled services, implement role‑spoof detection: 1) add a linear probe layer to your inference pipeline that flags anomalous role assignments; 2) audit prompt templates to ensure control tokens are unforgeable; 3) train models with adversarial examples that mix fake structure and content to harden against spoofing attacks.
