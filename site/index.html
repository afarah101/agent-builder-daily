Pinocchio: Fast Uncertainty Estimates for Black-Box Language Models

Kevin David Hayes, Arka Pal, Haosong Zhang, Tom Goldstein · Academic Institution · 21 Sep 2026

Pinocchio is a tool that gives confidence scores for answers from closed‑source language‑model APIs, without needing any internal access to the model. It was built as an external service that takes the model’s output and estimates how likely it is correct, and it improves the reliability of decisions made using these models. This is relevant if you run or audit AI‑driven services.

HOW TO APPLY THIS

If you manage an AI‑based service that calls a closed‑source LLM API, add Pinocchio to your stack: 1) pipe every model response through Pinocchio to get an uncertainty score; 2) set a threshold and block or flag responses below it; 3) monitor the score distribution to catch model drift or misuse.
