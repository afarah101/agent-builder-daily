PrivDrift: Auditing User-Secret Leakage Under Topic Drift in Active LLM Conversations

Luciano Maldonado · Academic Institution · 24 Sep 2026

PrivDrift is a tool that tests whether a large language model can still pull out sensitive user data after a conversation has shifted to different topics. It uses 1,000 simulated dialogues with hidden secrets and checks if the model can recover them through later prompts. The result shows that even after topic drift, many models still leak user secrets, highlighting a privacy risk.

HOW TO APPLY THIS

If you manage cloud‑based LLM services, add a post‑interaction audit step: 1) log all user prompts and responses; 2) run a PrivDrift‑style script to try retrieving any hidden secrets from later turns; 3) if secrets are recoverable, apply stricter data‑retention or masking policies.

From Agent Output to Authorized Transition

Christopher Koch · Academic Institution · 23 Sep 2026

The paper tackles the challenge of trusting autonomous agents that produce engineering outputs, like code or firmware, by proposing the Agile‑V Assurance Spine – an integrated framework that chains together sandboxing, approvals, tracing, policy checks and attestations. It builds a unified, end‑to‑end assurance workflow that ensures any agent‑generated artefact is verified before being acted on. The result is a clearer, more reliable chain of custody and evidence for deploying agent‑created assets.

HOW TO APPLY THIS

If you manage cloud infrastructure that uses AI agents to generate code or configuration, here is what to do: 1) integrate the Agile‑V Assurance Spine to capture and verify each agent output before deployment; 2) configure policy hooks to automatically block or flag outputs that fail trace or attestation checks; 3) audit the assurance logs regularly to maintain compliance with your organisation’s security standards.
