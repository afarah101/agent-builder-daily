Prune First, Decide Fast: Scalable Semantic Query Processing with JEVDB

Zhengle Wang, Hanxu Yan, Fuheng Zhao, Chunwei Liu · Academic Institution · 01 Oct 2026

JEVDB tackles the high cost and latency of semantic queries by using fast, typed decision models for most operations and only calling expensive LLMs when needed. It builds a scalable system that prunes joins with Yannakakis-style reductions and Semantic Bloom Filters, achieving faster responses and lower cost. For IT managers, the key takeaway is that this approach can make complex semantic queries cheaper and quicker if you can integrate it into your data stack.

HOW TO APPLY THIS

If you manage semantic query workloads, step 1: replace or augment your current LLM-heavy engines with a typed decision model for filtering, joining, and ranking; step 2: implement a Bloom filter layer to prune unlikely join candidates; step 3: route only uncertain results to the LLM to keep cost and latency down.
