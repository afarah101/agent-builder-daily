LLM2Jev: LLMs Are Already Jev-Style Decision Models -- When and How to Fine-Tune Them

Yinheng Li, Justin Wagle · Academic Institution · 01 Oct 2026

Jeves-style decision models give a clear choice from a set of options, useful for automated actions. The paper shows that many large language models (LLMs) can already do this without extra training, and offers a simple framework – LLM2Jev – to extract calibrated decisions from the model’s token probabilities. If you need reliable, action‑ready decisions from an LLM, this method lets you use the model as is or fine‑tune it with minimal effort, improving accuracy and trust in automated workflows.

HOW TO APPLY THIS

If you manage cloud infrastructure, here is what to do: 1. Identify a decision point in your system that needs a categorical outcome (e.g., scaling decision, alert routing). 2. Use LLM2Jev to wrap a pre‑trained LLM and extract the probability distribution over your options directly from token logits. 3. If the default calibration isn’t sufficient, fine‑tune the model with a small, task‑specific dataset using LLM2Jev’s objective to improve precision. This gives you an out‑of‑the‑box, low‑maintenance decision engine for your automation pipelines.
