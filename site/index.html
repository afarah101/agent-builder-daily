GateWatch: Low-Overhead LLM Monitoring with Boolean Circuits

Firas Spanioli, Yaniv David·18 Nov 2026

GateWatch offers a very lightweight way to watch what large language models (LLMs) do by turning a few key features into simple Boolean rules. They built a system that keeps memory use down by 99.98% and adds almost no lag when running many probes on a model like Gemma‑2‑9B. The result is accurate monitoring that almost matches heavier methods while staying fast and tiny.

How to apply: If you manage LLM deployments, add GateWatch to your monitoring stack: 1) Identify the key SAE features you need (about 4), 2) Deploy GateWatchServe to stream these binaries during inference, 3) Use the compact lookup tables to evaluate probes in parallel, keeping throughput above 97% and cache usage near 100%.

PIPETTE: Prompt Injection Purple-Teaming for Robust LLM Agents

Lipeng He, Yihan Wang, Jiawen Zhang, N. Asokan·18 Nov 2026

PIPETTE tackles prompt injection attacks on LLM agents by creating a purple‑team framework that pushes red‑team attacks to cover many strategies, then trains defenders with those attacks to build robust agents. It built a dictionary‑reward system for wider attack discovery and an on‑policy training pipeline that keeps normal tasks working while blocking injection. The result was agents with almost zero success for static attacks and strong resistance to adaptive attacks without losing performance.

How to apply: If you manage cloud‑hosted LLM services, use PIPETTE by: 1) integrating its dictionary‑reward red‑team to generate diverse injection scenarios, 2) feeding those scenarios into an on‑policy adversarial training loop for your models, 3) validating that attack success rates drop to near zero while task accuracy stays near baseline.

MaskPE: One Mask, Two Roles: Weight Placement and MAC Gating in Systolic Arrays

Shu-Lin Shih, Chandra Sekhar Mummidi, Aamir Gujral Elhaissouni, Sandip Kundu·19 Nov 2026

MaskPE tackles the gap between weight pruning and energy savings in systolic arrays by routing non‑zero weights to processing elements and clock‑gating zero‑weights, cutting compressed weight storage by 34.9% and reducing execution energy by up to 14.4% at 50% sparsity.

How to apply: If you manage a systolic‑array‑based inference engine, step 1: add a mask‑driven preload stage to send only non‑zero weights to the relevant PEs; step 2: enable clock‑gating on registers in PEs that receive zero‑weights; step 3: validate with RTL to ensure no stall or accuracy loss.

Sightline: Calibrated Data-Flow Summaries for LLM-Integrated Applications

Zihao Xu, Yuekang Li, Ruitao Feng, Haifeng Shen·19 Nov 2026

Sightline creates accurate data‑flow summaries for applications that call large language models, solving the problem of over‑tainting by showing which prompt placeholders actually influence LLM outputs. It uses a single forward pass and a small calibration set to prune over 40% of false flows while missing only about 1% of real ones. The result is a leaner, more precise flow analysis for LLM‑integrated code.

How to apply: If you manage LLM‑integrated services, here is what to do: step 1, run a small calibration set to determine the acceptable miss rate α; step 2, integrate Sightline to analyse each model call and prune unnecessary taints; step 3, review the pruned flow reports to reduce false positives in your security checks.
