HydroJEV: A one-second, training-free screen for cyber-attack and fault attribution in water distribution networks

Tianwei Mu, Shengyan Jiang, Mingzhe Yuan, Qing Luo · Academic Institution · 01 Oct 2026

When a SCADA alarm pops up in a water network, operators need to know fast if it’s a cyberattack, a physical fault, a normal glitch or a bad sensor. The authors built Jev, a training‑free model that gives a cause probability in about one second, eliminating the need for labelled data or slow LLMs. Jev achieved competitive accuracy on a four‑class benchmark for the C‑Town water network.

HOW TO APPLY THIS

If you manage SCADA or OT monitoring, you can add Jev as a first‑pass triage: 1) feed the alarm data into Jev to get instant cause probabilities; 2) use the top suggestion to trigger the appropriate incident response; 3) log the outcome for future training or audit. This reduces manual triage time and improves response accuracy.

PACE: Provenance-Aware Capability Enforcement for Tool-Using LLM Agents

Fengpeng Li, Qizhou Wang, Yuke Hu, Kemou Li · Academic Institution · 01 Oct 2026

Tool‑using LLM agents can be misdirected by poisoned tool data or memory, leading to unsafe actions. PACE intercepts every tool call, checks its provenance and context before execution, and blocks unsafe calls. This reduces the risk of unintended behaviour in automated systems using LLMs.

HOW TO APPLY THIS

If you manage cloud infrastructure that runs LLM‑based automation, add a PACE‑style middleware to your tool‑execution pipeline: 1) Log the provenance of each tool (source, version, checksum). 2) Before calling the tool, verify the provenance against an approved catalogue. 3) Block or audit any call that fails the check.
