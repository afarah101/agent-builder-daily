How Much of a Harness Does a Strong Agent Need for Autonomous ML Engineering?

Kirill Brilliantov, Alejandro Hernández-Cano, Emmanuel Abbé · Academic Institution · 30 Sep 2026

This study examines how much orchestration a strong autonomous machine learning engineering agent needs, finding that more primitive coding agents with direct environment access can reduce the reliance on complex orchestrators. The authors built a test framework to evaluate agents with varying levels of harness support and reported that minimal harnessing can still achieve competitive performance. The result suggests that simpler, direct‑control agents can be effective, potentially lowering infrastructure overhead.

Learning Functional Subspaces for Neural Network Compression

Massimo Bini, Anders Christensen, Stephan Alaniz, Judah Goldfeder · Academic Institution · 30 Sep 2026

Existing low‑rank compression of transformer weight matrices often hurts performance because it ignores how errors stack through the network. The authors built a learnable subspace selection method that optimises across layers to minimise overall loss. The result is tighter compression with little accuracy loss, making large models more memory‑efficient.

HOW TO APPLY THIS

If you manage ML workloads, use this method to compress models before deployment: 1) run the learnable subspace algorithm on your transformer, 2) benchmark accuracy vs. memory usage, 3) deploy the compressed model to reduce GPU/CPU footprint.
