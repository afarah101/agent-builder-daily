Yihong Zhou, Hongtai Zeng, Thomas Morstyn · Academic Institution · 2026-04-27

The problem of coordinating large populations of grid-edge devices is addressed through a novel AI approach called GradMAP, which trains independent neural-network policies for each agent without any parameter sharing. GradMAP uses a differentiable three-phase AC power-flow model in a primal-dual learning framework to enable decentralised decision-making. The outcome is a fully decentralised learning method that respects three-phase AC distribution-network physics, allowing for more efficient and flexible grid management.

HOW TO APPLY THIS

AI practitioners can apply the GradMAP approach by embedding differentiable physical models into their learning frameworks, enabling decentralised decision-making in complex systems. This can be particularly useful in applications where real-time communication between agents is not feasible, such as in grid-edge device coordination or other distributed control systems.
