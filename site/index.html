Reward Stealing Attack on Large Language Models

Jiaming Qian, Pengyang Zhou, Jiahe Xu, Chaochao Chen · Academic Institution · 05 Oct 2026

The paper shows a new way to trick LLMs by learning the model’s hidden safety reward from its outputs and then flipping that reward to produce harmful text. The authors built a framework that uses inverse reinforcement learning to recover this reward and generate attacks without needing the original training data. The result is a more scalable, model‑agnostic attack that can bypass safety filters on many LLMs.

OrigaMIG: MIG-Aware VM Placement with a Neighborhood-Restricted BILP and Live Migration

Ahmad Siavashi, Mahmoud Momtazpour · Academic Institution · 05 Oct 2026

This research tackles GPU fragmentation caused by NVIDIA’s Multi‑Instance GPU (MIG) placement rules in cloud data centres. The authors designed a bi‑objective integer linear programme that places VMs with MIG‑backed vGPUs so that fragmentation is reduced and resource utilisation is improved, achieving a 15‑20% higher GPU utilisation in simulations. It offers a concrete optimisation tool for cloud managers dealing with GPU‑heavy workloads.

HOW TO APPLY THIS

If you manage GPU workloads, implement the MIG‑aware placement algorithm: 1) model your VM pool and MIG‑backed vGPU requirements as a bi‑objective ILP; 2) run the optimisation before scheduling new VMs to minimise fragmentation; 3) integrate the ILP output into your cloud orchestrator to enforce the placement decisions.

CLIFT: Conformal Self-Verification for Web Agent Training and Test-Time Scaling

Yifan Zhang, Yutong Dai, Viraj Prabhu, Zhiyuan Hu · Academic Institution · 05 Oct 2026

CLIFT tackles the problem of training web‑browser agents with sparse rewards and expensive external judges by letting the agent ask itself verification questions during training; a conformal certifier then filters out uncertain answers. The method was built as a training pipeline that reduces the need for costly human or model‑based feedback, leading to more efficient learning and better scalability at test time. Mechanizing the User's Eye: Pre-Registered Deployment of a Sabotage-Validated Fail-Plausible Observer in a Production LLM Agent Runtime

Wei Wu · Academic Institution · 05 Oct 2026

This research tackles the problem of silent, fail‑plausible failures in LLM agent runtimes that slip through automated tests but are caught by a human eye. The team built an automated observer that monitors five deterministic signals to detect when an internal error could produce misleading, plausible user output, achieving a high detection rate. This is relevant to IT infrastructure managers because it offers a way to detect subtle runtime errors that could impact user experience and compliance.

HOW TO APPLY THIS

If you manage a production LLM service, implement the observer by: 1) instrumenting your runtime to emit the five key signals (e.g., model confidence, response latency, token anomaly, error logs, and context mismatch); 2) setting thresholds for each signal and triggering a fail‑plausible flag when multiple exceed limits; 3) routing flagged outputs to a safety review queue before they reach users.
