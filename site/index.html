JointServe: Serving Multi-Model Agents on Memory-Constrained GPUs

Daijin Hu · Academic Institution · 14 Oct 2026

JointServe lets you run multi‑model AI agents on GPUs that can’t hold all the models in memory by treating small weight shards and key‑value cache blocks as swap‑able objects, so you avoid serialised weight transfers and lost session state. The system was built to keep the GPU usage below the memory limits typical of private or edge deployments, and it achieved near‑native inference speed while supporting several expert models concurrently.

HOW TO APPLY THIS

If you manage GPUs with limited memory, 1) partition each model into shards and store them on host memory, 2) enable JointServe’s residency management to swap shards in and out as needed, and 3) configure KV cache blocks to be backed by host RAM to maintain session state during swaps.
