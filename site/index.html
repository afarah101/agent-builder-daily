KV-Kaizen: Learning Context-Adaptive Cache Compression Choices

Joao Monteiro, Louis Béthune, Anastasiia Filippova, Sonia Laguna · Academic Institution · 29 Sep 2026

The paper tackles the problem of large KV caches in LLM inference that consume too much memory and slow down decoding. The authors built KV‑Kaizen, a context‑adaptive cache‑compression selector that learns which cache entries can be safely compressed rather than evicted, and demonstrated up to 40 % memory savings with negligible accuracy loss. This is relevant for cloud operators running LLMs: it can improve throughput and reduce memory costs.

HOW TO APPLY THIS

If you manage LLM inference on the cloud, here is what to do: 1) Integrate KV‑Kaizen’s compression selector into your inference pipeline; 2) Tune its compression thresholds based on your workload’s context length; 3) Monitor performance to ensure accuracy remains within acceptable bounds.

ToolFence: Fine-Grained Authorization for Secure Tool-Using LLM Agents

Yanjie Li, Xiangyu He, Xuelong Dai, Bin Xiao · Academic Institution · 29 Sep 2026

ToolFence provides a fine‑grained permission system for tool‑using LLM agents, solving the problem of indirect prompt injection that current defence mechanisms fail to stop. The authors built a lightweight policy engine that checks each tool call against user‑defined authorisations, achieving a 60‑80% drop in successful attacks with negligible overhead. This directly benefits cloud infra managers by reducing the risk of compromised automated tooling in their environments.

HOW TO APPLY THIS

If you manage LLM‑enabled services, add ToolFence to your agent stack: 1) Define per‑tool permission policies for each user or service account, 2) Wrap the agent’s tool‑calling interface with ToolFence’s auth layer, 3) Monitor and log denied calls to detect suspicious patterns.

SKILLLITE: Evidence-Guided Malicious Skill Auditing with Compact LLMs

Haoran Ou, Gelei Deng, Xuanye Zhang, Wenbo Guo · Academic Institution · 29 Sep 2026

The paper tackles the problem of third‑party 'Agent Skills' that can be inserted into large language model (LLM) agents and may contain hidden malicious code, potentially compromising the host environment. The authors developed a lightweight audit framework that uses compact LLMs to analyse skill packages and flag suspicious behaviour, achieving high detection accuracy while keeping resource use low. This means if you run LLM agents that load external skills, you now have a practical tool to vet them before deployment.

HOW TO APPLY THIS

If you manage LLM‑based agents, first integrate the SKILLLITE audit tool into your CI pipeline: 1) Scan each skill package with the compact LLM auditor; 2) Review the generated risk report; 3) Block or sandbox any skill flagged as potentially malicious before it can be activated.
