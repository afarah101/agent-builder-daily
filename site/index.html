Reva: Real-Time Vulnerability Detection through Contextual Probing of Large Language Models

Amine Lbath, Massih-Reza Amini·26 Oct 2026

REVA solves the problem of slow, accurate vulnerability detection for new code. It combines threat models, static analysis and call-graph data into a single LLM forward pass with a probe, achieving 60% accuracy in about one second per function—about 250× faster and cheaper than existing agentic detectors. This means faster security checks with comparable or better accuracy.

How to apply: If you manage code deployments, here is what to do: 1) Integrate REVA into your CI pipeline to scan each new function before merging. 2) Provide REVA with pre‑computed threat models, lightweight static analysis results and call‑graph info. 3) Use REVA’s probe output to flag potential vulnerabilities and auto‑block merges that exceed your risk threshold.

FLOWSTEP: A Framework for Learning to Predict GitHub Actions Workflow STEPs

Jiangnan Huang, Bin Lin, Yutaro Kashiwa·26 Oct 2026

FLOWSTEP improves the accuracy of predicting which GitHub Actions steps to add to a CI/CD workflow from 38% to 51%, using a new model that separates reusable Actions from project‑specific Scripts and adds contrastive learning. This means developers can get better automated suggestions when building or updating GHA pipelines, potentially reducing errors and saving time. For cloud‑infrastructure managers, this tool offers a way to streamline CI/CD configuration, though it does not directly change your underlying cloud services.

How to apply: If you manage GHA workflows, do the following: 1) Replace your current step‑prediction tool with FLOWSTEP to get more accurate, context‑aware suggestions. 2) Validate the recommended steps with your own test runs. 3) Use FLOWSTEP’s LLM‑judge feature to automate sanity checks against your pipeline expectations.

Tingzhu Bi, Xun Zhang, Jinglin Li, Ping Wang·26 Oct 2026

The paper shows that simple, unprescribed LLM harnesses outperform complex, hand‑crafted RCA agents in diagnosing microservice failures, achieving 65‑77% precision.
