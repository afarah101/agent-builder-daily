OnTrack: Real-Time Monitoring and Intervention in LLM Agent Trajectories via Streaming Structure-Aware Optimal Transport

Babak Barazandeh, Connor Swanson, Chinmay Kulkarni, Nikhil Mungel · Academic Institution · 08 Oct 2026

OnTrack tackles the problem of costly and unsafe actions by autonomous LLM agents by providing a real‑time, streaming monitoring system that compares each step of an agent’s plan with a reference trajectory using structure‑aware optimal transport. The authors built a lightweight monitoring module that can be plugged into any LLM agent’s workflow, flagging deviations as they occur and allowing for immediate intervention. The result was a reduction in unsafe outcomes and lower operational cost compared to post‑hoc evaluation or safeguard agents that add latency.

HOW TO APPLY THIS

If you manage cloud infrastructure, here is what to do: 1) Identify any LLM‑driven services (e.g., automated incident triage or deployment bots) in your stack. 2) Integrate OnTrack’s streaming monitor as a side‑channel to the LLM’s output pipeline. 3) Configure the monitor to trigger a rollback or human‑review alarm when a deviation exceeds a predefined threshold.

SparseDecoding: Decoding-Aware Pruning for Accurate and Efficient LLM Inference

Qitong Wang, Xinwei Niu, Mingluo Su, Shanwei Zhao · Academic Institution · 08 Oct 2026

They developed SparseDecoding, a pruning method that uses the Hessian calculated on tokens the model itself generates during decoding, reducing memory read and cutting inference latency while keeping accuracy. The result is a lighter, faster LLM that can run with fewer resources. This can help you reduce cost and speed up inference on your cloud infrastructure.

HOW TO APPLY THIS

If you manage LLM inference on the cloud, do the following: 1. Identify your deployment’s bottleneck – the memory read during decoding. 2. Apply SparseDecoding’s pruning, which recomputes the Hessian on self‑generated tokens, not on static data. 3. Deploy the pruned model and monitor latency and cost savings.

Agentic AI-Assisted Modeling for Production Scheduling: Assessment in Constraint Programming

Ángel Sánchez-Fernández, Javier Pernas-Álvarez, Diego Crespo-Pereira · Academic Institution · 07 Oct 2026

The paper investigates whether general-purpose large language models, run as agents, can automatically create and solve production scheduling optimisation models, a task that usually needs specialist expertise. The authors built an agent‑orchestrated system that translates natural‑language problem descriptions into constraint‑programming models and then solves them, showing that the approach can produce workable schedules but with mixed performance. The work is largely research‑focused and does not directly impact typical cloud‑infrastructure management.
