GreyZone is a benchmark that tests automated red‑team tools on real, production‑grade agent applications. BitDecoding-FP4: Native FP4 KV Cache Decoding via Algorithm-System Co-Design

Dayou Du, Woon Yee Ng, Guangming Sheng, Nick Lau·06 Nov 2026

BitDecoding‑FP4 tackles the accuracy‑bandwidth trade‑off in 4‑bit KV cache decoding for LLMs by combining new quantisation tricks with hardware‑level softmax optimisation. It delivers near‑BF16 accuracy while boosting serving throughput 2.4–3× on NVIDIA GPUs. This is relevant for cloud infra that hosts large‑context LLMs, offering a way to reduce memory use and increase performance.

How to apply: If you manage GPU‑based LLM serving, check if your KV cache uses 4‑bit formats: 1) integrate BitDecoding‑FP4’s dual‑residual query quantisation and outlier‑aware key quantisation into your model export; 2) enable transposed softmax with fused probability quantisation on your GPU kernel; 3) benchmark throughput against BF16 to confirm the 2–3× gain.

FOSCAR: Accelerating Decode Attention over 2- and 4-Bit KV Caches through Affine Folding

Donglin Zhuang, Pragaash Ponnusamy, Xiaoxia Wu, Shuaiwen Leon Song·06 Nov 2026

FOSCAR tackles the slow decoding of large‑language models by using affine folding to skip costly scale‑and‑offset operations on 2‑bit and 4‑bit key‑value caches, and by packing these values efficiently for Tensor Cores. The authors built highly specialised GPU pipelines for Hopper (H100) and Blackwell (B200) that deliver 2–3× speedups over existing FP8 and BF16 solutions, boosting long‑context serving throughput by up to 341%.

Intent-Aware Caching for Efficient LLM Serving

Kazi Hasan Ibn Arif, JinYi Yoon, Dimitrios S. Nikolopoulos, Hans Vandierendonck·MIT·06 Nov 2026

The research tackles the low hit‑rate problem in LLM prefix caching by using user intent to predict when a conversation will continue. They built an online eviction policy that classifies requests by intent, learns reuse stats, and evicts based on those stats, achieving a 34.6% hit‑rate and up to 46% lower latency. This directly benefits cloud‑based LLM services, improving resource utilisation and response times.

How to apply: If you manage LLM inference infrastructure, implement an intent‑aware cache: 1) add a lightweight intent classifier to your request pipeline, 2) log recent intent‑specific reuse patterns, 3) adapt your cache eviction policy to favour prefixes from intents with high continuation rates.

When Instruction Files Go Stale: Documentation Debt and Hidden Cost in Coding Agents

Tural Mehtiyev, Biruk Tadesse, Lawrence Arkoh, Wesley Assunção·06 Nov 2026

Stale instruction files cause coding agents to make extra tool calls, adding hidden cost to every run. The authors analysed three real‑world cases, showing that correcting or removing stale docs cuts unnecessary operations. For cloud infra managers, this means keeping agent configs up to date can save time and reduce waste.

How to apply: If you manage AI‑powered coding agents, here is what to do: 1) Regularly audit and update your instruction files (e.g., AGENTS.md) to match current repo structure. 2) Remove obsolete sections rather than leaving them stale. 3) Monitor agent run logs for extra tool calls that may indicate stale guidance.
