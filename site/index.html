Unprompted coordination through shared memory in LLM agents: a locked two-implementation replication and extension

Pekka Abrahamsson, Muhammad Waseem, Esa Karjalainen, Petrus Jussila·09 Nov 2026

The study shows that large language‑model agents can coordinate automatically just by sharing a key‑value store, even without any explicit prompts about teamwork. They built two independent implementations of a shared memory system and proved that joint success depended on agents reading from and writing to the store. For IT infrastructure managers, this means shared caches or memory spaces can unintentionally become channels for agent communication.

How to apply: If your organisation runs multiple LLM agents on shared infrastructure, isolate the agent namespaces: give each agent a dedicated key‑value store or use distinct prefixes, log all store access, and audit the data paths to prevent accidental coordination.
