Closing the Gap: Automated Discovery of Secure Dockerfile Reference Standards via Semantic Clustering in Enterprise Inner Source

Jessica Hösl, Benedikt Hofmann, Patrick Stöckle·26 Aug 2026

Many enterprise Dockerfiles contain security misconfigurations and outdated practices, with 99% showing at least one flaw. The authors built a six‑step automated pipeline that crawls GitLab, enriches each Dockerfile with security metrics, clusters them by LLM‑derived semantics, and finds internal reference implementations. Using these references can raise the average security score by 60% without writing new templates.

How to apply: If you manage Dockerfile repos, run a similar pipeline: 1) crawl your GitLab instance and run static checks (Hadolint, Trivy, ShellCheck) on all Dockerfiles; 2) cluster similar files using an LLM to generate semantic tags and HDBSCAN to group them; 3) for each cluster, identify the highest‑scoring Dockerfile and replace or copy it into your own projects to improve security and consistency.

BI-Agent and BI-Bench: Towards Automating End-to-End Business Intelligence

Chuxuan Hu, Yeye He, Penny Zhou, Wee Hyong Tok·16 Sep 2026

BI-Agent uses large language models and specialised data tools to automate the whole business intelligence process – from finding the right tables, transforming data, joining tables, to answering business questions. The authors built a benchmark (BI-Bench) from real dashboards and a tool‑augmented agent that improves accuracy by up to 40% over vanilla LLMs. This research is relevant if you manage BI workloads on cloud platforms, as it shows a way to reduce manual data prep and improve query accuracy.

How to apply: If you manage BI dashboards in Power BI or Tableau on the cloud, adopt a tool‑augmented agent approach: 1) integrate an LLM with data‑search, join, and transform tools; 2) train it on your own BI project logs using supervised fine‑tuning or reinforcement learning; 3) deploy the trained agent to automatically process user questions and return answers, cutting manual prep time by up to 40%.
