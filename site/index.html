Kaijun Zhou, Qiwei Chen, Da Peng, Zhiyang Li · Academic Institution · 2026-04-27

GradMAP: Gradient-Based Multi-Agent Proximal Learning for Grid-Edge Flexibility

Yihong Zhou, Hongtai Zeng, Thomas Morstyn · Academic Institution · 2026-04-27

The problem of coordinating large populations of grid-edge devices in a decentralized manner while respecting three-phase AC distribution-network physics is addressed. The proposed AI approach, GradMAP, uses gradient-based multi-agent proximal learning to train independent neural-network policies for each agent. The outcome of this approach is a fully decentralized learning method that can learn to make online decisions without communication between agents.

Nirmit Joshi, Roey Magen, Nathan Srebro, Nikolaos Tsilivis · MIT · 2026-04-27

The problem of learning from multiple thinkers is studied, where each thinker provides correct but possibly systematically different solutions. The AI approach involves using Chain-of-Thought (CoT) supervision from multiple thinkers to learn classes that are computationally easy to learn with CoT supervision from a single thinker. The outcome establishes that learning can be hard from CoT supervision under cryptographic assumptions.
