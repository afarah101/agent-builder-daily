JointServe: Serving Multi-Model Agents on Memory-Constrained GPUs

Daijin Hu · Academic Institution · 14 Oct 2026

JointServe solves the problem of running multi-model LLM agents on GPUs that do not have enough memory to hold all model weights simultaneously. It builds a serving system that treats weight shards and KV blocks as independent residency objects, allowing selective loading and host‑backed KV restoration. The result is a significant reduction in weight transfer overhead and the ability to run complex agents on memory‑constrained GPUs without losing session state.

HOW TO APPLY THIS

If you manage edge GPUs, here is what to do: 1) install JointServe on your GPU nodes, 2) configure weight shard residency for each expert model, 3) enable host‑backed KV restoration to keep session state across model switches.

Han-Sang Lee, Kyuho Lee, Juneyoung Park, Seongbae Lee · Academic Institution · 14 Oct 2026

The research shows how to fit a 1.2B Korean language model onto mobile NPUs by trimming vocab and head layers, reducing memory to about 1 GiB and keeping call‑time latency low. It solves the problem of running private, low‑cost AI call agents on device instead of the cloud. The result is a lightweight model that meets strict thermal, memory and latency constraints while maintaining near‑cloud quality.
