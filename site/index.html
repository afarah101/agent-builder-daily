Metrics Failure in LLM-Based Code Vulnerability Repair: An Empirical Study and a Change-Aware Screen

Om Nepal, Sushant Aryal, Oluseyi Olukola, Nick Rahimi · Academic Institution · 22 Sep 2026

The paper shows that using compile success as a metric for automated LLM‑generated vulnerability patches is unreliable – it barely changes even when the underlying code improves. The authors ran controlled tests on 203 C/C++ functions with three open‑source LLMs and three prompting methods and found that compile rates do not reflect true repair quality. For cloud engineers, this means you can’t trust a simple compile check to gauge the safety of LLM‑fixed code.

HOW TO APPLY THIS

If you deploy LLM‑generated patches in your CI pipeline, stop relying solely on compile success. Instead, add a security‑review step or run dynamic analysis to validate vulnerability fixes. Check that your build system logs not just compilation but also functional and security tests before promotion.
