JetStream: Generating Verified Query Accelerators for Existing Database Systems

Akhilesh Balasingam, Amadou Ngom, Geoffrey X. Yu, Tim Kraska · Academic Institution · 14 Oct 2026

JetStream creates query‑specific accelerators that sit on top of an existing database system, using the DBMS’s own tables and adding optional helper state. It lets you keep your current data and ad‑hoc queries while boosting performance for a fixed set of templated queries. The result is faster execution for those queries without needing a full data migration or a new database engine.

HOW TO APPLY THIS

If you manage a database system, here is what to do: 1) Identify the most common query templates you run; 2) Run JetStream’s staged agentic workflow to generate an accelerator for those templates; 3) Deploy the accelerator on top of your existing DBMS and monitor the performance gains.

Decoupled Marginal Sharpening for Training-Free Inference-Time Scaling

Weixin Wang, Wei Deng, Anderson Schneider, Yuriy Nevmyvaka · Academic Institution · 14 Oct 2026

This research tackles the problem of making large language models reason better at inference time without retraining them or needing external reward models. The authors developed a decoupled marginal sharpening technique that reshapes the model’s probability distribution during inference to favour higher‑probability completions, achieving improved reasoning performance in tests. The approach is a pure inference‑time trick that requires no model updates and offers faster, higher‑quality outputs.
