Cap-and-Track: Optimizing LLM Inference Request Dispatch Across Shifting Capacity

Benjamin Novotny, Doug Szeto, Chang Wang, Shicheng Chen·18 Nov 2026

Cap-and-Track lets you adapt LLM inference dispatch to changing GPU capacity and request size without hard‑coding a rate. They built an async dispatcher that rejects requests early when resources are full, then uses those refusals to probe capacity and refill queues, cutting GPU use by 43% in production. It’s relevant to anyone managing AI inference fleets, offering a way to save hardware while keeping high‑priority work on time.

How to apply: If you manage GPU fleets for LLM inference, use Cap-and-Track by: 1) Add a fail‑fast admission check that rejects over‑capacity requests; 2) Log refusals and use them to back‑off and probe current capacity; 3) Keep short‑lived queues in the inference engine to batch efficiently. This will reduce GPU usage and improve throughput without manual retuning.

GateWatch: Low-Overhead LLM Monitoring with Boolean Circuits

Firas Spanioli, Yaniv David·18 Nov 2026

GateWatch offers a very lightweight way to watch what large language models (LLMs) do by turning a few key features into simple Boolean rules. They built a system that keeps memory use down by 99.98% and adds almost no lag when running many probes on a model like Gemma‑2‑9B. The result is accurate monitoring that almost matches heavier methods while staying fast and tiny.

How to apply: If you manage LLM deployments, add GateWatch to your monitoring stack: 1) Identify the key SAE features you need (about 4), 2) Deploy GateWatchServe to stream these binaries during inference, 3) Use the compact lookup tables to evaluate probes in parallel, keeping throughput above 97% and cache usage near 100%.

PIPETTE: Prompt Injection Purple-Teaming for Robust LLM Agents

Lipeng He, Yihan Wang, Jiawen Zhang, N. Asokan·18 Nov 2026

PIPETTE tackles prompt injection attacks on LLM agents by creating a purple‑team framework that pushes red‑team attacks to cover many strategies, then trains defenders with those attacks to build robust agents. It built a dictionary‑reward system for wider attack discovery and an on‑policy training pipeline that keeps normal tasks working while blocking injection. The result was agents with almost zero success for static attacks and strong resistance to adaptive attacks without losing performance.

How to apply: If you manage cloud‑hosted LLM services, use PIPETTE by: 1) integrating its dictionary‑reward red‑team to generate diverse injection scenarios, 2) feeding those scenarios into an on‑policy adversarial training loop for your models, 3) validating that attack success rates drop to near zero while task accuracy stays near baseline.

Mechanistic Critics for Sample-Efficient NPU Design-Space Exploration

Yicheng He, Yuqi Xue, Tianyang Wu, Jian Huang·18 Nov 2026

CriticNPU is a tool that speeds up designing neural processing units (NPUs) for large‑language‑model inference by using a fast, physics‑based model to guess whether a new hardware setup will be faster before running a slow simulator. It filters out poor candidates early and then refines the design using real simulation data, cutting the number of expensive simulations in half while matching or beating the best latency in most test cases. This directly helps IT engineers who design or optimise custom AI chips or select cloud AI services, giving a faster way to pick the right hardware configuration for specific workloads.

How to apply: If you manage NPU or AI workload optimisation, here is what to do: 1) Run CriticNPU’s Roofline model with your target architecture parameters to get quick pre‑simulation estimates of compute and memory bottlenecks. 2) Filter out designs that the critic flags as unlikely to beat your current best. 3) Simulate only the promising candidates and let CriticNPU’s post‑simulation analysis suggest the next parameter tweaks to hit the lowest latency for prefill and decode stages.
