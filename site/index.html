When the Agent Becomes the Kernel: A Systematization of Security on the Path to AI-Native Operating Systems

Li Zhang, Yang Sun, Jie Shi · Academic Institution · 20 Sep 2026

Large‑language‑model agents now act like operating‑system kernels, making changes to code, mail, and purchases without a trusted mediator. The authors propose a security framework that ensures any agent action is mediated by a provenance check, giving a deterministic way to verify trust. The result is a set of design principles that could guide the creation of AI‑native OSes and similar systems.

HOW TO APPLY THIS

If you manage cloud infrastructure, check whether your automated agents (e.g., CI/CD pipelines, auto‑scaling scripts, AI‑assistants) perform all privileged actions through a provenance‑based mediator; if not, add a layer that records and validates each agent’s action history before execution. This flags a risk: if your organisation uses any AI‑powered automation without such checks, immediately audit for unmediated access paths.

One to More, More to One: Category-Aware Iterative Expert Training for Software Engineering Agents

Jie Zhao, Ziyu Jiang, Suhang Zheng, Minghui Shan · Academic Institution · 20 Sep 2026

The study tackles uneven performance across different software engineering task categories when using reinforcement learning agents. It introduces a category‑aware training framework, including a task construction tool and an evidence‑based labeling system, which together raise overall training success rates. This is directly relevant for IT teams that deploy AI agents in multi‑domain development workflows.

HOW TO APPLY THIS

If you manage cloud‑based AI agents for software engineering, step 1: identify the task categories your agents handle and note any performance dips. Step 2: integrate a category‑aware training pipeline that isolates and trains on each category separately, using a label system to validate results. Step 3: merge the specialised policies back into your main agent and monitor for improved, balanced performance across all categories.
