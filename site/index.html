LLM2Jev: LLMs Are Already Jev-Style Decision Models -- When and How to Fine-Tune Them

Yinheng Li, Justin Wagle · Academic Institution · 01 Oct 2026

Jev-style decision models give machines clear, numbered choices instead of messy text, so software can act on them directly. The authors made LLM2Jev, a framework that pulls these choice probabilities straight from any LLM’s next‑token scores, with a simple rule‑based method and a small fine‑tuning option if needed. In tests, the approach worked without extra training and produced reliable, calibrated decisions, saving developers time on custom classifiers.

HOW TO APPLY THIS

If you manage cloud infrastructure, here is what to do: 1) Identify any workflows that currently parse LLM output into action‑able decisions, 2) Replace the parsing step with LLM2Jev by feeding the LLM a prompt that ends with bracketed numeric IDs, 3) If you need higher accuracy, fine‑tune your LLM on a small set of decision examples using the provided objective.

PACE: Provenance-Aware Capability Enforcement for Tool-Using LLM Agents

Fengpeng Li, Qizhou Wang, Yuke Hu, Kemou Li · Academic Institution · 01 Oct 2026

PACE is a security framework for large‑language‑model agents that use external tools; it tracks the origin of each tool call and enforces access controls before execution. The researchers built a mediator that checks tool provenance in real time to block malicious or unintended actions. For cloud infrastructure managers, this research does not directly impact routine operations.
