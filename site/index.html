BI-Agent and BI-Bench: Towards Automating End-to-End Business Intelligence

Chuxuan Hu, Yeye He, Penny Zhou, Wee Hyong Tok · Academic Institution · 16 Sep 2026

The paper tackles the tedious manual steps of building BI reports by training a large language model to auto‑identify tables, transform data and answer queries end‑to‑end, creating the BI‑Agent tool and a benchmark (BI‑Bench). It shows that the model can generate correct answers with minimal user input, dramatically cutting BI prep time.

HOW TO APPLY THIS

If you manage BI workflows, set up an LLM‑based assistant to auto‑generate queries and data models: 1) feed your data catalogue to the model, 2) prompt it with the business question, 3) review and publish the returned data model and visualisation.
