LOCAA: An Agentic System for Automated Lossy Compressor Tuning

Khondoker Mirazul Mumenin, Dong Dai, Sheng Di, Franck Cappello · Academic Institution · 07 Oct 2026

LOCAA tackles the tedious task of tuning lossy compression settings for large scientific datasets by using a large‑language model to predict the best error‑bound that balances storage savings and data quality. It builds an automated system that recommends compressor configurations, cutting the need for manual trial‑and‑error. The result is faster deployment of efficient compression with fewer resources spent on exhaustive search.

HOW TO APPLY THIS

If you manage storage or data pipelines that use lossy compression, integrate LOCAA into your workflow: 1. Feed your dataset metadata and desired quality metrics into LOCAA; 2. Use the generated error‑bound recommendation to configure your compressor; 3. Monitor compression ratio and output quality, adjusting only if the results deviate from expectations.
