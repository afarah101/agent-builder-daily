Replication of Agentic Security Events: Audit and Investigation (ROGUE-AI)

Mengxiao Wang, Mahbub Alam, Kalyan Nakka, Nitesh Saxena·19 Nov 2026

ROGUE‑AI builds a test framework that re‑creates real incidents involving LLM agents, such as accidental file deletion or payment fraud, and shows that the agents reproduce the harm 89% of the time. The system identifies hidden hazards—like shared databases—and demonstrates that simple post‑output warnings about the danger cut damage significantly. This research highlights that even well‑behaving agents can cause serious infrastructure harm if they act on unsafe instructions, so it is relevant to cloud‑infrastructure managers.

How to apply: If you manage cloud infrastructure that uses LLM‑based agents, step 1: replicate any past incidents with ROGUE‑AI or a similar tool to see if your agents can reproduce the harm. Step 2: identify shared resources (e.g., databases, file shares) that the agents might access. Step 3: add a post‑tool‑output warning that names the hazard and its consequence before executing any action to reduce damage.

HiSA: Sparsifying the Hidden Dimension of RoPE Attention in LLMs

Ambroise Borbely, Mathieu Salzmann, Olivier Verscheure·19 Nov 2026

HiSA removes part of the dot product in the feature dimension of RoPE attention, keeping only about a third of the calculations while matching or improving model performance. The authors built a static, parameter‑free rule that sparsifies hidden‑dimension interactions, trained LLMs from scratch, and extended the method to FlashAttention‑3 for faster inference and lower memory use.

How to apply: If you manage cloud infrastructure, here is what to do: 1) Monitor memory usage of your LLM inference services; 2) Evaluate adopting HiSA to cut per‑token attention cost by ~66%, reducing GPU memory footprint and speeding up response times; 3) Test the HiSA implementation with FlashAttention‑3 in your deployment pipeline to confirm performance gains.

Validation-driven Deployment of LLM Inference Platforms for Agentic Workloads

Shai Gretz, Alon Halfon, Yoav Katz, Lena Dankin·19 Nov 2026

The research tackles the problem of reliably validating and scaling large language model (LLM) deployments for agentic workloads. The team built an end‑to‑end evaluation pipeline that uses replayed real‑world traces and synthetic tests to benchmark token load, concurrency and throughput, proving that captured traces can accurately simulate live workloads while revealing hidden code‑coverage gaps. The result is a set of open‑source tools and a trace dataset that enable teams to more confidently deploy and tune large, mixed‑expert models.

How to apply: If you manage LLM inference infrastructure, use the pipeline: 1) capture real user sessions as traces; 2) replay those traces to generate per‑session token loads that stay within 1.2× of the real workload; 3) run the same workload on live and synthetic data to expose code‑coverage gaps and adjust concurrency settings to reach optimal throughput.

Amine Lbath, Manan Suri, Aurelien Delaitre, Vadim Okun·19 Nov 2026

Large language model (LLM) agents can now find, confirm and fix software bugs without human help, and open‑weight models have reached similar levels of autonomy. If your organisation relies on third‑party software, check for LLM‑patched CVEs immediately.
