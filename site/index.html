Same Query, Different Answer: Run-to-Run Variance in Semantic Query Processing

Oktie Hassanzadeh, Dharmashankar Subramanian · Academic Institution · 09 Oct 2026

Semantic query engines that use LLMs to decide on each row can produce different results on successive runs even when the LLM temperature is set to zero. The authors re‑ran benchmark workloads a million times to measure how often and how many rows change outcome, finding up to 24% variation for some tasks. This shows that run‑to‑run variance is a real issue for LLM‑powered data pipelines.

HOW TO APPLY THIS

If you manage LLM‑based query processing, check your consistency checks: 1) run each query multiple times and flag rows that change, 2) implement a tolerance threshold (e.g., <5% change) before committing results, 3) use higher temperature or ensemble methods only when variance is within acceptable limits.
