CoGate: Confidence-Gated Co-Decoding for Secure Code Generation

Minghao Hu, Lannan Luo, Allen Roush, Phillip Howard · Academic Institution · 30 Jul 2026

This research solves the problem of large language models generating insecure code by introducing a confidence-gated co-decoding approach, which builds on existing co-decoding methods by considering the expert model's confidence, resulting in more secure code generation. The researchers built a system called CoGate, which combines a target model with a small expert model at each step to generate secure code. This approach improves the security of code generated by large language models.

HOW TO APPLY THIS

If you manage cloud infrastructure that uses large language models for code generation, here is what to do: review your current co-decoding approach, consider implementing CoGate or a similar confidence-gated co-decoding method, and evaluate its impact on the security of your generated code.
