SARA: SLO-Aware Resource Allocation for Disaggregated Agentic LLM Services

Shicong Liu, Xianghao Yu, Zhen Gao, Jun Zhang · Academic Institution · 22 Sep 2026

SARA tackles the challenge of efficiently allocating cloud resources for long‑context LLM inference by using service‑level objectives (SLOs) to guide the distribution of compute across disaggregated systems. The authors built a framework that automatically adjusts resource allocation based on real‑time SLO monitoring, and they demonstrated a measurable reduction in cost while meeting latency targets.

HOW TO APPLY THIS

If you manage cloud infrastructure for LLM services, here is what to do: 1) deploy SARA to collect SLO metrics and current resource utilisation, 2) use its optimisation module to redistribute GPU/CPU time across your disaggregated nodes, 3) monitor the resulting latency and cost impact to validate the model’s effectiveness.

Toolcompass: Guiding Tool Trialing, Not Suppressing It

Junlin Fang, Chong Zhang, Do Nguyen-Thanh, Xiaogang Xu · Academic Institution · 22 Sep 2026

ToolCompass helps large‑language‑model agents decide when to try new tools, reducing wasted trials while still exploring unfamiliar tools. It builds a post‑training framework that groups tool calls by function and guides agents to choose trials that are likely useful. The result is fewer unnecessary calls and better use of interaction budgets. This is relevant for any organisation deploying LLM‑powered tools.

HOW TO APPLY THIS

If you manage cloud infrastructure that uses LLM agents to trigger scripts or services, here is what to do: 1) integrate ToolCompass into your agent pipeline to map tool calls by function; 2) configure the guidance thresholds to match your interaction budget; 3) monitor trial counts and adjust to keep trials focused on high‑value functions.
