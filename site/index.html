Authority at Commit Time: Reject-and-Rerun Semantics for Governed Agentic Systems

Jesus Salas · Academic Institution · 25 Sep 2026

The research tackles the problem that automated agents can act on outdated policy or system state, risking unapproved changes. The authors built a governance service that, at the moment an agent proposes an action, checks the current state and verifies the proposal; if it is still valid the action is reserved for execution, otherwise it is rejected and must be retried. The result is that only up‑to‑date, authorised actions are allowed, preventing stale or unauthorized changes from reaching the infrastructure.

HOW TO APPLY THIS

If you manage cloud infrastructure with automated change agents, 1) integrate a commit‑time verification step that checks proposals against the latest state, 2) reject any action that no longer matches current policies or resources, 3) queue approved actions for idempotent dispatch to your cloud platform.

AGATE: Provenance-Based Runtime Defense Against Compositional Attacks on LLM Agents

Xiaorui Zhang, Zhuoran Cheng, Kailin Liu, Zhaoxi Sun · Academic Institution · 25 Sep 2026

AGATE is a runtime defence for large‑language‑model agents that tracks where data comes from and who authorises each action, then limits what the agent can do based on those rules. It was built as a gate between an agent and its host, using operator declarations, grants and an effect ledger to enforce data provenance and authorization. The result was a system that can prevent compositional attacks by ensuring every step a model takes is authorised and its data origins are traceable.

HOW TO APPLY THIS

Not directly applicable to IT infrastructure work.
