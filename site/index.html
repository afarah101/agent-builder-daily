MultiAlloc: Budget-Aware Precision Allocation for KV Cache Quantization

Yangchengyu Zhou, Zhiping Wu, Runchang Jiang, Dongdong Ren · Academic Institution · 13 Oct 2026

Large language model inference uses a lot of memory for the KV cache. MultiAlloc solves this by budgeting how many bits to give each part of the cache under a fixed memory limit, keeping accuracy high. The result is a more efficient cache that uses the same space but delivers better performance.

HOW TO APPLY THIS

If you manage KV cache for LLMs, use MultiAlloc by: 1) set a total memory budget for the cache; 2) run the MultiAlloc algorithm to decide bit‑precision for each token/layer; 3) apply those precisions during inference to keep accuracy while staying within budget.

Junkai Lin, Ge Xu, Zheng Xu, Junkai Chen · Academic Institution · 13 Oct 2026

This research tackles the problem of LLM agents leaking sensitive data that they picked up during training. The authors built a machine‑unlearning technique that removes specific unwanted knowledge from an already‑trained agent without retraining from scratch, and showed it keeps the agent’s overall performance intact. If you do not deploy LLM agents, this work is not directly relevant to your day‑to‑day IT infrastructure duties.

HOW TO APPLY THIS

If your organisation uses LLM agents, check whether those agents were trained on private data; if so, apply the authors’ parameter‑level unlearning method to scrub the model before deployment, then re‑evaluate its performance on core tasks.
