Chuan Liu, Shuoming Zhang, Zhicheng Li, Qianqi Sun · Academic Institution · 29 Sep 2026

The authors built a lightweight runtime that detects changing workloads and reconfigures the model without draining requests. This can improve utilisation and reduce latency for diverse workloads.

Effective Dense Retrieval using Only In-Context Examples

Nour Jedidi, Abdul Basit Ali, Hang Li, Jimmy Lin · Academic Institution · 29 Sep 2026

RICE shows that large language models can produce good dense retrieval vectors without any training, using only a few examples in the prompt. The authors built a simple in‑context prompting method that aligns query and document representations, and achieved retrieval performance that matches or exceeds traditional trained retrievers. This means you can skip the costly embedding model training step and still get strong search results.

HOW TO APPLY THIS

If you manage a cloud search service, step 1: add a few example query‑document pairs to your prompt; step 2: let your LLM generate embeddings for new queries and documents on the fly; step 3: index those embeddings in your vector store and run nearest‑neighbour search. This flags a risk: if your org uses a custom retriever model, check whether RICE could replace it and save compute and engineering effort.
