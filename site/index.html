Self-Evolving Agent Harness

Chuyang Wei, Haoxiang Guan, Minghang Zhu, Kexin Zhou · Academic Institution · 13 Oct 2026

This paper introduces a system that lets an AI agent automatically tweak its own prompts, memory, workflows and code while keeping the core model unchanged, aiming to make the agent more adaptable and efficient. The authors built a framework that separates what can be changed from how changes are suggested and accepted, using evolutionary optimisation and PAC‑learning to keep updates reliable. The result is a more self‑sufficient agent that can improve over time without needing new model training.

Hybrid Reasoning Agents

Jiaru Zou, Yunzhe Qi, Sirui Chen, Federico Bianchi · Academic Institution · 13 Oct 2026

Hybrid Reasoning Agents combine hidden (latent) reasoning with text-based interaction so an AI can think internally and act through language. The authors built a lightweight module, HybridLink, that lets the agent switch between these modes during a single generation step. The result is a more efficient, transparent agent that still uses natural language to communicate with users.

Back-Translation Still Matters: Leveraging Monolingual Data for Low-Resource Machine Translation with LLMs

Divyanshu Bathla, Parag Singla, Jitin Singla · Academic Institution · 13 Oct 2026

The paper shows that using back‑translation on moderate amounts of monolingual data improves low‑resource machine translation with large language models, even better than extra pre‑training. The authors fine‑tuned an LLM, back‑translated monolingual sentences to create synthetic parallel data, and then retrained the model, boosting translation quality for scarce languages. This research is relevant if you work with multilingual data pipelines or need to support languages with little parallel data.

HOW TO APPLY THIS

If you manage multilingual data pipelines, here is what to do: 1) Gather moderate monolingual corpora for your target language. 2) Use your fine‑tuned LLM to back‑translate these sentences into the source language to generate synthetic parallel pairs. 3) Retrain or fine‑tune the LLM on this expanded dataset to improve low‑resource translation performance.
