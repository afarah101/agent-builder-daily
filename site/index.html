KV-Kaizen: Learning Context-Adaptive Cache Compression Choices

Joao Monteiro, Louis Béthune, Anastasiia Filippova, Sonia Laguna · Academic Institution · 29 Sep 2026

KV‑Kaizen learns how to shrink the key‑value cache of a large language model without throwing away useful data, letting the model keep running faster when the context grows. The team built a lightweight selector that predicts which cache entries can be compressed, and in tests the compressed cache stayed as effective as the full one while cutting memory use by up to 40%. For cloud operators this means you can host larger context models on the same hardware or serve more users at lower cost.

HOW TO APPLY THIS

If you manage LLM services, step 1: instrument your KV cache to expose entry sizes and hit patterns; step 2: deploy a KV‑Kaizen‑style selector (or similar) to mark compressible entries; step 3: enable dynamic compression on those entries during decoding and monitor performance and accuracy. Check for any library updates that expose this feature.

ToolFence: Fine-Grained Authorization for Secure Tool-Using LLM Agents

Yanjie Li, Xiangyu He, Xuelong Dai, Bin Xiao · Academic Institution · 29 Sep 2026

ToolFence tackles the problem of indirect prompt injection in LLM agents that use external tools, which can trick the agent into giving malicious tool calls. It implements fine‑grained authorisation that verifies each tool action against a policy, reducing the success rate of such attacks. The result is stronger security for tool‑using agents, but it adds some processing overhead.

HOW TO APPLY THIS

If you manage an organisation that deploys LLM agents calling APIs or scripts, check whether your agents enforce per‑action authorisation. First, audit your current agent workflows for shared context between instructions and tool outputs. Second, integrate ToolFence or a similar policy engine to vet each tool call before execution, and monitor for performance impact.

Hyewon Suh, Thanh Minh Nguyen, Chih-Lun Lee, Darrow Hartman · Academic Institution · 29 Sep 2026

The paper tackles the inefficiency of re‑planning every run of a repeated workflow by teaching a system to learn a reusable policy. It builds a neuro‑symbolic framework that encodes stable decisions (ordering, loops, branches) as code while leaving dynamic checks to a neural component, resulting in faster, more reliable task execution. For IT infrastructure this offers a way to automate recurring cloud‑management scripts with less overhead.

HOW TO APPLY THIS

If you manage cloud infra, here is what to do: 1. Identify a workflow that repeats often (e.g., VM provisioning, backup scripts). 2. Use the neuro‑symbolic framework to train a policy on a few example runs, capturing the fixed structure. 3. Deploy the learned policy to replace manual or scripted re‑planning, monitoring for any unexpected dynamic checks.

SKILLLITE is a lightweight tool that uses small language models to audit third‑party agent skills for malicious behaviour, helping organisations spot hidden threats before they run in a production LLM‑based agent. The study shows the tool can detect malicious patterns with high accuracy while keeping resource use low, but it does not directly affect traditional cloud infrastructure management.
